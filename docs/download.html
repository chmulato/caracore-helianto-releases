Templates de infraestrutura — avaliação técnica

Docker Compose, Caddyfile e nginx.conf para montar um ambiente de avaliação. O aplicativo Helianto Condominium não está incluído.

Os templates descrevem a infraestrutura prevista (contêineres Docker, proxy reverso e HTTPS automático) para que equipes técnicas avaliem o desenho de deploy antes do lançamento. Nada aqui está pronto para operação em produção.

Como montar um ambiente de avaliação

Os arquivos estão disponíveis para download direto no repositório de releases no GitHub. Para avaliar o desenho da infraestrutura:

Fluxo de avaliação:

  1. Instale o Docker e o Docker Compose em uma VPS Linux de teste.
  2. Baixe o template docker-compose.prod.yml.
  3. Revise as variáveis de ambiente e ajuste um arquivo .env local.
  4. Valide o compose: docker compose -f docker-compose.prod.yml config
  5. Os serviços api e web dependem dos artefatos da aplicação, ainda não publicados. Para avaliar a rede, suba apenas o banco: docker compose -f docker-compose.prod.yml up -d postgres

Os templates de proxy e infraestrutura do ecossistema:

docker-compose.prod.yml Caddyfile (SSL autônomo) nginx.conf (proxy reverso)

Requisitos do servidor (referência)

  • Sistema Operacional: Ubuntu Server 22.04 LTS ou superior (64-bit)
  • Mínimo: 1 vCPU, 2 GB RAM (avaliação de infraestrutura)
  • Recomendado: 2 vCPUs, 4 GB RAM (ambiente de testes com mais serviços)
  • Armazenamento: 20 GB de espaço SSD
  • Software: Docker Engine 24.0+ e Docker Compose v2.0+ instalado

Requisitos para operação em produção serão publicados junto com a v1.0.0.

Verificação e segurança

Os templates já impedem a exposição pública da porta 5432 do PostgreSQL. A higienização de logs (PrivacyGuard - LGPD Shield) e a autenticação via JWT fazem parte do aplicativo, que está em desenvolvimento e não acompanha estes arquivos.
